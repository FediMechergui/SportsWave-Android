# Emulator evidence

Selected screenshots and metadata support TEST_REPORT.md and OPTIMIZATION_AUDIT.md. Screenshots show the actual observed state, including blank/buffering and corrupted output; they are not polished product mockups. Early filenames reflect capture attempts and may not match the final screen shown.

Network metadata contains host/type/status and initiator information, not response bodies, request headers, URL queries or signing credentials. The root audit directory, raw UI dumps and local inspection scripts are not published.

The native HLS sample is the public Mux test stream of Big Buck Bunny. Film credit: Big Buck Bunny, Blender Foundation / peach.blender.org, Creative Commons Attribution 3.0. Provider names and team artwork shown in screenshots belong to their respective owners and are included as diagnostic interface evidence.
