# SportsWave 1.0.0-beta.2

Fixes VIPRow's detached-loader timeout and Livekora channel redirects that previously prevented player discovery. Adds all 19 VIPRow sports, Relevance/Kickoff/League sorting, explicit commentary-language groups, and a Channels menu independent of match availability.

Arryadia/SNRT playback has been verified on the emulator with visible video and advancing playback time. AlbaPlayer's Cast-plugin namespace crash is corrected, and observed player dependencies are scoped to reviewed hosts. This remains a prerelease: the sampled beIN media request stalled, other providers are not certified, and channel availability does not guarantee a particular match broadcast. KooraTV/KorahLive schedules and verified live scores remain limited.

The APK is directly installable on Android 8.0+. The AAB is for store tooling. Both use the existing release signing identity. SHA256SUMS.txt accompanies the downloads. See TEST_REPORT.md for actual validation and remaining limitations.

Validation: 24 offline tests; signed/minified APK installed on Android 15; VIPRow loaded 195 football events; Arryadia video and landscape fullscreen verified; APK signature/alignment and AAB validation passed. Native HLS rendered a sample frame after buffering, with sustained playback still unverified.
