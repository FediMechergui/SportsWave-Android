# SportsWave 1.0.0-beta.1

Initial signed Android prerelease with the new SportsWave launcher icon, source repository and build documentation.

## Downloads

- **SportsWave-1.0.0-beta.1.apk**: signed release APK for direct installation on Android 8.0 or newer.
- **SportsWave-1.0.0-beta.1.aab**: signed Android App Bundle for store tooling; not directly installable.
- **SHA256SUMS.txt**: SHA-256 checksums of the APK and AAB.
- **SIGNING-CERTIFICATE-SHA256.txt**: public fingerprint of the release-signing certificate.

If an earlier debug build is installed, remove it before installing this signed release because its signing identity differs. Removing the debug build deletes its local data. Future release updates will retain this release-signing key.

## Included

- Adaptive, vector and monochrome app icon with a mint wave/play mark.
- Native VIPRow catalogue, sport/status filters, search, refresh, event grouping and crest fallback.
- Published player discovery with Arabic label preservation, deduplication and YasirTV URL recognition.
- Explicit nested TodayStreams → DaddyLive → Dembed permissions and reviewed resource dependencies.
- Native Media3 HLS/DASH and embedded WebView engines with retry/back/switch-server controls.
- Signed, minified APK and signed AAB; Gradle wrapper and CI debug builds.
- 19 offline regression tests, provider documentation and a comprehensive optimization audit.

## Known limitations

This is an experimental beta, not a claim of reliable live-stream support. The sampled web player remained buffering after required requests were permitted. Native HLS rendered an initial frame but later showed green corruption in the Android 17 emulator. Live scores are not implemented: current live indicators come from scheduled times. Seven sport categories are configured; full 19-category VIPRow coverage and the MMA route correction remain pending. KorahLive script-generated resolver behavior and KooraTV playback are unsupported/unverified. Complete Arabic localization/RTL is planned.

See the repository's README, TEST_REPORT.md and OPTIMIZATION_AUDIT.md for actual results and remaining work. No source access keys or signing credentials are included in this release.
