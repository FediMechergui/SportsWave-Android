# Arabic and Tunisian default — 18 October 2026

The development build defaults to **Arabic & Tunisia · all sports**. It retains the combined international feeds and all 20 sports, prioritizes Tunisian competition names in relevance ordering, and prioritizes Arabic catalogue providers on otherwise comparable entries. It does not filter other sports out. Kickoff and League sorts remain available. Arabic commentary choices already precede English and unverified players.

The Sources directory initially enables its Arabic/Tunisian filter; users can disable it. Watania, Diwan Sport, beIN guide/CONNECT and beIN Match and the researched Yacine websites are watch-resource handoffs across every sport. They are service links, not evidence that the selected match is being broadcast.

## Yacine / Yassin findings

- [yacinetv.website](https://yacinetv.website/) returned HTTP 200 to an ordinary request. Its public HTML contains no static player iframe and references a separate match API. The readable page currently exposes a match-loading error. Previous Robotiva research did not yield an independently verified player integration. An HTML response is not video verification.
- [yacinetv.dev](https://www.yacinetv.dev/) publishes a match/server interface and a 24/7 channel selector. It describes external channel and embed API sources; the readable page exposes zero populated servers. It is included as a separate, unverified browser choice. No affiliation with the Android app is established.
- [yt.yacineapp.tv](https://yt.yacineapp.tv/) redirects to [yacineapk.tv](https://www.yacineapk.tv/), an app-download page. It does not expose a usable public all-beIN channel feed in the inspected page. No APK was installed or reverse engineered.
- The supplied spelling `beinwatchatv.com` failed DNS resolution locally and could not be opened by the web tool. No matching result identified a corrected domain. The user subsequently corrected it to [beinmatchatv.com](https://beinmatchatv.com/). An ordinary request returned HTTP 200 with an Arabic football page, no static iframe or anchor player links, and the same external Kora match API used by yacinetv.website. It is added as an unverified browser handoff, not an all-beIN native feed. Automatic approval review blocked a follow-up API probe with the reason blocked by policy; that probe did not run.

No universal beIN stream list, channel IDs, access credentials or player URLs were invented. Existing published channel pages remain separate from match calendars. A website's Arabic interface is not proof of a stream's commentary language.
